# Contributing

Forgeline is pre-alpha and currently maintained by one person. Issues and design
feedback are welcome now. Code contributions are easiest after milestone M1 lands, when
the pipeline spec stops moving.

- Run `make ci` before opening a pull request. It runs vet, tests, and a build.
- Keep changes small and focused, and explain the reason for a change in the description.
- Design changes to the pipeline spec, the trust model, or the extension interfaces start as
  a written proposal in `docs/` so they can be discussed before code is written.
